# calculadoras-importacion

- **Framework:** Astro 7.x (SSG) con Tailwind CSS v4 (@tailwindcss/vite)
- **Estilos:** Tailwind CSS
- **Estructura:**
  - `/src/components` — componentes reutilizables
  - `/src/data` — datos estáticos (tarifas, aranceles, tipos de cambio, etc.)
  - `/src/pages` — rutas del sitio
  - `/src/layouts` — layouts compartidos
- **Reglas:**
  - Código TypeScript estricto (`astro/tsconfigs/strict`)
  - Componentes semánticos (HTML semántico, sin `div` innecesarios)
  - Sin fuentes ni librerías pesadas externas
